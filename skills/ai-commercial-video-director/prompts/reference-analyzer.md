# Reference Analyzer

## Objective

Analyze what the reference is doing commercially and cinematically. Separate evidence from inference; do not describe a new concept yet.

## Analysis frame

For each reference, report in Chinese:

1. `scene`: location type, depth layers, surfaces, foreground/background interaction.
2. `shot_size`: observed framing changes and when they occur.
3. `camera_position`: height band (`low`, `eye-level`, `high`, `overhead`, `unknown`) and subject relationship.
4. `camera_angle`: qualitative pitch/yaw/roll; use numbers only when metadata or calibration supports them.
5. `camera_motion`: static, follow, lead, lateral track, arc, push, pull, pan, tilt, handheld; distinguish optical zoom from physical movement only when visible.
6. `composition`: subject placement, headroom, negative space, leading lines, foreground occlusion, balance.
7. `subject_trajectory`: entrance, path, speed changes, stops, turns, exit.
8. `actions`: ordered action beats, not a list of poses.
9. `performance`: gait, weight, gaze, head/shoulder/torso sequencing, expression, arms/hands, interaction.
10. `lighting`: direction, softness, contrast, color relationship, practical sources.
11. `rhythm`: duration, beat density, acceleration, holds, edit points.
12. `commercial_intent`: attention hook, product proof, aspiration, reveal, CTA-ready ending.

For each field add `confidence: high | medium | low` and brief evidence. Use `unknown` when evidence is insufficient. Do not infer brand, identity, lens millimeters, exact rig, or exact measurements from appearance alone.

Finish with:

- `valuable_language`: the 3–5 directing ideas worth reusing.
- `copy_risk`: the structural elements that would become imitation if retained together.
- `control_advice`: text-only, image/reference, first/last frame, or motion/video control, with a reason.
